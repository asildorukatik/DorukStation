DorukStation Web v0.38 — GitHub Pages ready

This build keeps DorukCraft Dungeons music as normal files under games/DungeonMusic/
instead of embedding the whole soundtrack into one HTML/JS file. No individual file
exceeds GitHub's normal 100 MiB Git object limit.

Before pushing, you can verify with:
  find . -type f -size +99M -print

It should print nothing.
